# CarryCtx Website Repository Instructions

This repository is reserved for the future CarryCtx website. Do not implement the website until the `carryctx-cli` v0.1 behavior and public documentation are stable and a website design has been approved in `../carryctx-docs/`.

- Treat CLI documentation as the source for public product claims.
- Keep this repository independent from sibling Git histories.
- Put temporary files in `../tmp/`.
- Use Conventional Commits.
