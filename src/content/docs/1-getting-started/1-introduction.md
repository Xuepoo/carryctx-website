CarryCtx is an offline-first, Git-native context persistence engine. It lets you seamlessly switch between tasks, save snapshots, and hand off workflows to AI agents without losing context.

## Core Features
- **100% Offline & Local**: Zero latency, all state stored in `.git/carryctx/state.sqlite`.
- **AST Syntax Graph**: Gives AI spatial awareness.
- **Git Worktree Integration**: Automatically infers the current branch and task.
