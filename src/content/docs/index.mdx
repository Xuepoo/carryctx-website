## Core Features

<p class="ctx-lede ctx-reveal">
  CarryCtx is a local-first, Git-native context engine built for coding agents and the humans
  working alongside them. It lets work continue seamlessly across windows, sessions, and agents.
</p>

<CardGrid stagger>
  <Card title="100% Offline & Local" icon="approve-check-circle">
    Zero latency. All state lives in `.git/carryctx/state.sqlite`. No cloud account required.
  </Card>
  <Card title="Git Worktree Aware" icon="code-branch">
    Automatically infers the current branch, worktree, and active task, so context never needs re-declaring across sessions.
  </Card>
  <Card title="AST Dependency Graph" icon="puzzle">
    Scans code dependencies to give AI spatial awareness, reducing hallucinated cross-file assumptions.
  </Card>
  <Card title="Agent Agnostic" icon="rocket">
    Claude Code, OpenCode, Copilot, or a human developer: everyone shares the same structured project memory.
  </Card>
</CardGrid>

## Why not just Markdown notes?

<div class="ctx-reveal">
<CardGrid>
  <Card title="Structured, not prose" icon="list-format">
    Tasks, checkpoints, and decisions are queryable rows, not paragraphs an agent has to re-parse from scratch every session.
  </Card>
  <Card title="Git-native truth" icon="code-branch">
    Branch, HEAD, dirty state, and diffs are captured automatically. Never manually transcribed, never stale.
  </Card>
  <Card title="Built for hand-off" icon="random">
    Any agent, in any worktree, resumes with `carryctx resume`. No chat history to re-read, no context to rebuild.
  </Card>
</CardGrid>
</div>

## How it works

<div class="ctx-reveal">
<Steps>
1. **Initialize once.** `carryctx init` creates a local SQLite store inside your repo's `.git/` directory. Nothing leaves your machine.
2. **Claim a task.** Register your agent identity, create or claim a task, and start a session. CarryCtx infers the rest from your current worktree.
3. **Work normally.** Log `progress`, drop a `checkpoint` before you stop, and let CarryCtx capture the Git diff alongside your notes.
4. **Resume anywhere.** A new window, a new agent, or a teammate runs `carryctx resume` and picks up exactly where you left off.
</Steps>
</div>

## See it in action

<div class="ctx-reveal">
<Tabs>
  <TabItem label="Initialize">
    ```bash
    carryctx init
    carryctx agent register --name my-agent --provider user
    ```
  </TabItem>
  <TabItem label="Work">
    ```bash
    carryctx task create --title "Ship the exporter"
    carryctx task claim CTX-0001
    carryctx progress todo "Wire up the CSV writer"
    ```
  </TabItem>
  <TabItem label="Checkpoint">
    ```bash
    carryctx checkpoint \
      --done "Implemented CSV writer" \
      --remaining "Add streaming support"
    ```
  </TabItem>
  <TabItem label="Resume">
    ```bash
    carryctx resume
    # Task CTX-0001, last checkpoint 12m ago,
    # branch feature/csv-export, 2 files dirty.
    ```
  </TabItem>
</Tabs>
</div>
